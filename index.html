Структура документа

HTML-документ складається з оголошення типу <!DOCTYPE html> та кореневого елемента <html>, який містить дві частини: <head> (службова інформація: кодування, заголовок вкладки, підключення стилів) і <body> (видимий вміст сторінки).

<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Заголовок</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>…</header>
  <main>…</main>
  <footer>…</footer>
</body>
</html>

Тег — службове слово в кутових дужках, яке вказує браузеру, як відобразити вміст (парні <p>…</p> і непарні <img>). Атрибут — додаткова властивість тега у форматі назва="значення".

HTML-код таблиці

    <section id="catalog">
      <h2>Популярні книги</h2>
      <table>
        <tr><th>Обкладинка</th><th>Назва</th><th>Автор</th><th>Наявність</th></tr>

        <tr><td><img src="images/book3.svg" alt="HTML і CSS" width="50"></td><td>HTML і CSS</td><td>Джон Дакетт</td><td>Видана</td></tr>
      </table>
    </section>

Теорія

  • <table> — контейнер таблиці; <caption> — заголовок таблиці;
  • <thead>, <tbody>, <tfoot> — шапка, тіло, підвал;
  • <tr> — рядок; <th> — клітинка-заголовок; <td> — звичайна клітинка;
  • атрибути: colspan — об'єднання стовпців, rowspan — об'єднання рядків, border, width, align, scope (останні візуальні краще задавати в CSS).

HTML-код зображення

<img src="images/hero.svg" alt="Полиця з книгами BookNest" width="900" height="320">

Теорія

Тег <img> непарний. Атрибути: src — шлях до файлу (обов'язковий); alt — альтернативний текст (доступність, показується при помилці завантаження); width, height — розміри; title — підказка; loading="lazy" — відкладене завантаження. Для підпису використовують <figure> та <figcaption>. Формати: JPEG, PNG, GIF, SVG, WebP.

          <ul>

              <ul><li>Українська</li><li>Зарубіжна</li></ul>
            </li>
          </ul>
        </li>
        <li>IT</li>
      </ul>

Теорія

  • <ul> — маркований список; <ol> — нумерований; <li> — елемент списку;
  • атрибути <ol>: type (1, A, a, I, i), start, reversed; атрибут value для <li>;
  • <dl>, <dt>, <dd> — список визначень;
  • вкладені списки утворюють багаторівневу структуру.

HTML-код форми

<form> (атрибути action, method), <input> (type: text, email, radio, checkbox…; name, placeholder, required), <label for>, <select>/<option>, <fieldset>/<legend>, <button>.

Способи підключення стилів

  1. Вбудований (inline) — атрибут style:
    <p style="color:red">Текст</p>
  2. Внутрішній — тег style в head:
    <style>
  p { color: red; }
</style>
  3. Зовнішній — окремий файл (використано в проєкті):
    <link rel="stylesheet" href="style.css">
  4. Імпорт: @import url("style.css");

Каскадування — вирішення конфліктів правил за пріоритетом (inline > id > class > тег, а за рівної специфічності — останнє правило). Спадкування — передача деяких властивостей (color, font) від батьківського елемента нащадкам.

Селектори ідентифікаторів

Інші селектори

Дочірній nav > a, сусідній h2 + p, атрибута input[type="text"], універсальний *.

Я навчився підключати стилі різними способами та застосовувати селектори тегу, класу, ідентифікатора, а також дочірні, сусідні, атрибутні й універсальний селектори.   6. Приклади: font-family, font-size, color, text-align, text-decoration, line-height.
