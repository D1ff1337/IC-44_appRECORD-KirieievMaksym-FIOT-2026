Опис предметного середовища

Предметна галузь — бібліотечна справа. BookNest — онлайн-бібліотека, де читачі шукають книги в каталозі, бронюють їх і читають онлайн, а бібліотекар керує каталогом і видачею.

  • Пошук книг у каталозі.
  • Реєстрація читачів.
  • Бронювання і повернення книг.
  • Керування каталогом (бібліотекар).

Бізнес-логіка

  1. Читач переглядає каталог.
  2. Реєструється або входить.
  3. Знаходить і бронює книгу.
  4. Бібліотекар підтверджує видачу на 14 днів.
  5. Після повернення книга знову доступна.

Структура документа

HTML-документ складається з оголошення типу <!DOCTYPE html> та кореневого елемента <html>, який містить дві частини: <head> (службова інформація: кодування, заголовок вкладки, підключення стилів) і <body> (видимий вміст сторінки).

<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Заголовок</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>…</header>
  <main>…</main>
  <footer>…</footer>
</body>
</html>

Тег — службове слово в кутових дужках, яке вказує браузеру, як відобразити вміст (парні <p>…</p> і непарні <img>). Атрибут — додаткова властивість тега у форматі назва="значення".

HTML-код таблиці

    <section id="catalog">
      <h2>Популярні книги</h2>
      <table>
        <tr><th>Обкладинка</th><th>Назва</th><th>Автор</th><th>Наявність</th></tr>
        <tr><td><img src="images/book1.svg" alt="Кобзар" width="50"></td><td>Кобзар</td><td>Тарас Шевченко</td><td>Є</td></tr>
        <tr><td><img src="images/book2.svg" alt="Чистий код" width="50"></td><td>Чистий код</td><td>Роберт Мартін</td><td>Є</td></tr>
        <tr><td><img src="images/book3.svg" alt="HTML і CSS" width="50"></td><td>HTML і CSS</td><td>Джон Дакетт</td><td>Видана</td></tr>
      </table>
    </section>

Теорія

  • <table> — контейнер таблиці; <caption> — заголовок таблиці;
  • <thead>, <tbody>, <tfoot> — шапка, тіло, підвал;
  • <tr> — рядок; <th> — клітинка-заголовок; <td> — звичайна клітинка;
  • атрибути: colspan — об'єднання стовпців, rowspan — об'єднання рядків, border, width, align, scope (останні візуальні краще задавати в CSS).

HTML-код зображення

<img src="images/hero.svg" alt="Полиця з книгами BookNest" width="900" height="320">

Теорія

Тег <img> непарний. Атрибути: src — шлях до файлу (обов'язковий); alt — альтернативний текст (доступність, показується при помилці завантаження); width, height — розміри; title — підказка; loading="lazy" — відкладене завантаження. Для підпису використовують <figure> та <figcaption>. Формати: JPEG, PNG, GIF, SVG, WebP.

HTML-код списків

    <section id="rules">
      <h2>Як взяти книгу</h2>
      <ol>
        <li>Зареєструйтесь.</li>
        <li>Знайдіть книгу в каталозі.</li>
        <li>Забронюйте її.</li>
      </ol>
      <h3>Категорії</h3>
      <ul>
        <li>Художня література
          <ul>
            <li>Класика
              <ul><li>Українська</li><li>Зарубіжна</li></ul>
            </li>
          </ul>
        </li>
        <li>IT</li>
      </ul>
    </section>

Теорія

  • <ul> — маркований список; <ol> — нумерований; <li> — елемент списку;
  • атрибути <ol>: type (1, A, a, I, i), start, reversed; атрибут value для <li>;
  • <dl>, <dt>, <dd> — список визначень;
  • вкладені списки утворюють багаторівневу структуру.

HTML-код форми

    <section id="register">
      <h2>Реєстрація читача</h2>
      <form action="#" method="post">
        <label>Ім'я: <input type="text" name="name" required></label>
        <label>Email: <input type="email" name="email" required></label>
        <label><input type="checkbox" name="news"> Отримувати новини</label>
        <button type="submit" class="btn">Зареєструватися</button>
      </form>
    </section>

<form> (атрибути action, method), <input> (type: text, email, radio, checkbox…; name, placeholder, required), <label for>, <select>/<option>, <fieldset>/<legend>, <button>.

Висновки до ЛР №1

Під час роботи я створив репозиторії на GitHub, склонував їх та працював у Visual Studio Code. Описав предметну галузь (онлайн-бібліотека BookNest) та її бізнес-логіку, виконав макет у Figma. Створив головну сторінку веб-застосунку із заголовками різних рівнів, таблицею, зображеннями, нумерованими й маркованими списками, формою та посиланням на сторінку з описом. Ознайомився зі структурою HTML-документа, тегами та атрибутами, а також із публікацією сайту через GitHub Pages.

Контрольні питання

  1. Структура HTML-документа: DOCTYPE, html, head, body.
  2. Тег — інструкція браузеру в кутових дужках, що визначає тип і відображення елемента.
  3. Таблиці: table, caption, thead, tbody, tfoot, tr, th, td, colgroup, col.
  4. Зображення: img, figure, figcaption, picture, source.
  5. Списки: ul, ol, li, dl, dt, dd.
  6. Засоби опису таблиць: теги table/tr/td/th, атрибути colspan, rowspan, border, а також стилі CSS (border-collapse, padding тощо).
