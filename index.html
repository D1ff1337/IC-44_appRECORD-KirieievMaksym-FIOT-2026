Структура документа

HTML-документ складається з оголошення типу <!DOCTYPE html> та кореневого елемента <html>, який містить дві частини: <head> (службова інформація: кодування, заголовок вкладки, підключення стилів) і <body> (видимий вміст сторінки).

<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Заголовок</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>…</header>
  <main>…</main>
  <footer>…</footer>
</body>
</html>

Тег — службове слово в кутових дужках, яке вказує браузеру, як відобразити вміст (парні <p>…</p> і непарні <img>). Атрибут — додаткова властивість тега у форматі назва="значення".

Теорія

  • <table> — контейнер таблиці; <caption> — заголовок таблиці;
  • <thead>, <tbody>, <tfoot> — шапка, тіло, підвал;
  • <tr> — рядок; <th> — клітинка-заголовок; <td> — звичайна клітинка;
  • атрибути: colspan — об'єднання стовпців, rowspan — об'єднання рядків, border, width, align, scope (останні візуальні краще задавати в CSS).

HTML-код зображення

<img src="images/hero.svg" alt="Полиця з книгами BookNest" width="900" height="320">

Теорія

Тег <img> непарний. Атрибути: src — шлях до файлу (обов'язковий); alt — альтернативний текст (доступність, показується при помилці завантаження); width, height — розміри; title — підказка; loading="lazy" — відкладене завантаження. Для підпису використовують <figure> та <figcaption>. Формати: JPEG, PNG, GIF, SVG, WebP.

Способи підключення стилів

  1. Вбудований (inline) — атрибут style:
    <p style="color:red">Текст</p>
  2. Внутрішній — тег style в head:
    <style>
  p { color: red; }
</style>
  3. Зовнішній — окремий файл (використано в проєкті):
    <link rel="stylesheet" href="style.css">
  4. Імпорт: @import url("style.css");

Каскадування — вирішення конфліктів правил за пріоритетом (inline > id > class > тег, а за рівної специфічності — останнє правило). Спадкування — передача деяких властивостей (color, font) від батьківського елемента нащадкам.

Завдання №1. Зовнішній вигляд макету. Код макету

Макет сайту BookNest вдосконалено: додано шапку з логотипом і навігацією, блок карток переваг, картки книг, багатоколонковий підвал, а також правила перебудови блоків для трьох типів пристроїв.

Тип макету

Використано адаптивний (responsive) гумовий макет: ширина блоків задається у відсотках, rem, vw та через flex/grid, тому сторінка розтягується й стискається разом із вікном. Для трьох діапазонів ширини (desktop, tablet, mobile) використовуються медіа-запити, які змінюють кількість колонок і вигляд меню. Порівняно з фіксованим макетом (ширина в px) він зручніший на різних пристроях, але складніший у розрахунку; порівняно з чистим гумовим — не розтягується безмежно (max-width: 70rem) і не «ламається» на вузьких екранах.

js/menu.js

// Бургер-меню: відкриття/закриття навігації на малих екранах
const burger = document.getElementById("burger");
const menu = document.getElementById("menu");

function setMenu(open) {
  menu.classList.toggle("open", open);
  burger.classList.toggle("active", open);
  burger.setAttribute("aria-expanded", String(open));
  burger.setAttribute("aria-label", open ? "Закрити меню" : "Відкрити меню");
}

burger.addEventListener("click", () => setMenu(!menu.classList.contains("open")));
// закриття меню після вибору пункту
menu.querySelectorAll("a").forEach(a => a.addEventListener("click", () => setMenu(false)));
// закриття клавішею Esc
document.addEventListener("keydown", e => { if (e.key === "Escape") setMenu(false); });
// при збільшенні вікна меню скидається
window.matchMedia("(min-width: 601px)").addEventListener("change", e => { if (e.matches) setMenu(false); });

Особливості макету

  • Семантика: header (логотип + nav), main із section та article-картками, footer з контактами.
  • Flexbox: шапка (justify-content: space-between), картки книг (flex-wrap, flex: 1 1 …), підвал.
  • Grid: блок переваг (grid-template-columns: repeat(4, 1fr)).
  • Відносні одиниці: rem (відступи, шрифти), % (flex-basis, ширини), vw (бічні поля 4vw), vh (max-height: 45vh для hero), em-залежні розміри через успадкування.
  • Анімації: поява секцій і карток (@keyframes fadeUp), плавне відкриття мобільного меню (slideDown), підкреслення пунктів меню, підняття карток та зміна кольору кнопок при наведенні (transition), перетворення «бургера» на хрестик.

Адаптивна верстка: десктопна, планшетна та мобільна версії

Метатег viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Без нього мобільний браузер відображає сторінку у віртуальному вікні ~980px і зменшує її. Значення width=device-width задає ширину layout viewport, що дорівнює ширині екрана пристрою, а initial-scale=1.0 — початковий масштаб 100%.

Як створювалася кожна версія

  1. Десктоп — базові стилі без медіа-запитів: гнучкі контейнери (flex, grid) і обмеження max-width: 70rem.
  2. Планшет — діапазонний запит перебудовує сітки на 2 колонки (repeat(2, 1fr), flex-basis: calc((100% − gap)/2)) і переносить меню на окремий рядок (flex-basis: 100%).
  3. Мобільна — .burger стає видимою (display: flex), nav ховається та показується класом .open, який перемикає js/menu.js; сітки переходять в одну колонку.

Особливості макету

  • Меню — display: flex; flex-wrap: wrap, кнопка міста розтягується через flex: 1 1 10rem.
  • Програма курсу — рядок із трьох flex-блоків (justify-content: space-between): лічильник годин, список тем, фоновий напис; кнопка вирівнюється align-self: flex-end.
  • Тарифи — три картки у flex-wrap контейнері; у кожній картці flex-direction: column і margin-top: auto на блоці ціни, щоб ціни й кнопки були на одному рівні в усіх картках.
  • Банер і QA-блок — justify-content: space-between, align-items: center.
  • Шрифт Montserrat підключено локально через @font-face; фотографію викладача замінено власною SVG-ілюстрацією.
  • Адаптивність: на планшеті картки по 2 в ряд і ховається фоновий напис, на мобільному — одна колонка.
